# M5 manual evaluation protocol

Status: optional future work. The current personal-use scope defers manual
Orca listening and recruited participant sessions.

Run in the existing private offline Fedora X11 image with synthetic learning
data. Use the installed candidate and record its RPM digest, fixture
identity, viewport, theme, text size, keyboard layout, Orca version and
speech settings. No screenshots or personal learning data are needed.
Record anonymous participant codes, task results and qualitative barriers.

Recruit 5–8 participants across people new to collection tools and
experienced users. Include keyboard and assistive technology users where
feasible. Tell participants that the session evaluates the interface.
Disclose synthetic data, the observer's notes and the option to stop.
Do not infer learning efficacy from this sample.

| Task | Observe |
| --- | --- |
| A. Create a blank subject and learning goal | Find controls, recover after a typo, explain where the goal was saved. |
| B. Import a small synthetic dataset | Correct a mapping, check original attribution and explain which rows were applied. |
| D. Resume saved work offline | Open the saved session and verify the previous response or cursor. Start a due item and identify why it was offered. |
| E. Inspect practice evidence | Explain the difference between self-report, an unassessed attempt and a judgment on an older revision. |
| F. Personalize and reset | Find text size, shortcut and scope controls. Restore context and reset one category while keeping the rest. |
| G. Restore a supported backup | Confirm what the backup includes and open the isolated restored course. Verify settings and recent history. |

For Orca, listen to actual playback at the beginning, middle and end of
the synthetic catalog. Record the observed control name, role, selection,
position and total. Repeat after a search, sort and archive/restore, then
return to the prior location. Test at ordinary and enlarged text sizes.
Check focus remains visible and designates the intended control. Check
light and dark text/focus contrast and reduced-motion behavior separately.
Record a barrier with the trigger and whether participants can recover.

Report completion, assistance, incorrect choices and usability issues
as counts with sample limitations. Keep speech log assertions separate
from human playback results. This protocol has no participant results yet.
