# KER-112 typed content persistence

Implemented [KER-112](https://linear.app/kerigan/issue/KER-112/m24-persist-organization-resources-and-revisions-through-typed) on dev: schema3 relational organization storage, immutable document revisions/current heads, annotations and reading positions through the bounded single-writer service. Native adapters construct local authority internally and expose only main-window typed commands. No SQL, caller paths or principal payload is exposed.

The migration preserves existing preferences, asset records and operation receipts; transactional rollback leaves schema2 intact. Content writes validate workspace/nested references and revisions atomically, retain exact idempotency receipts and never replace immutable revisions. Annotation IDs cannot be retargeted to another resource/revision. Persisted annotation/reading-position anchors and nil revision UUIDs are checked before read results are returned. Durable source bytes remain in the existing managed asset service.
