# Operating live tools

Filter current metadata by provider/capability and print bounded names before loading schemas. Do not commit a workstation inventory as project knowledge. Load a specialist skill only when its workflow applies.

Inspect required fields, allowed values, pagination, data destination, cost, and write effects. Local/hosted schemas may differ. Recheck after session changes or a concrete schema failure, not before every unchanged call.

Batch independent reads with `Promise.allSettled` and inspect every result. Sequence dependencies, approvals, and mutations. Pass real newlines in structured issue bodies. For shell-generated bodies use a temporary file and `--body-file`; JSON stringification is not shell escaping.

Before authorized codebase delegation, gather graph/search/coverage evidence. Pass tier, scope, project/generation, symbols/paths, pagination, missed ranges/reasons, source fallback, and unresolved questions. Do not assume the child has parent tools. Delegate only when useful and authorized; avoid redundant investigation and polling loops.

Retry only for a clear correctable failure. Do not install services, change system configuration, expose endpoints, run credential setup, or broaden policies to repair an unrelated task. Preserve completed work and describe blockers precisely.

Keep credentials, personal learning data, sensitive payloads, and private source out of unauthorized external calls. Public retrieval, local source reads, and external mutations have distinct boundaries.
